# Lorebase

Long-form learning marketplace prototype. Dense lessons across AI, programming, data, cloud, security, marketing, business, and creative skills.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## What’s included

- Home, catalog (search + category filters), lesson pages, pricing
- Demo purchase panel on each lesson (no real payments yet)
- Markdown lessons in `/content` with frontmatter

## Review tip

Open a few lessons end-to-end and judge whether the depth feels worth `$11–24` each or a `$29` library pass.
